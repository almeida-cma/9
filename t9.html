📖 O que é Encapsulamento?

Encapsulamento é o princípio da POO que consiste em ocultar os detalhes internos de uma classe e fornecer uma interface controlada para acessar e modificar seus atributos.

📚 TRÍADE DIDÁTICA:
  • CONCEITO: Ocultar dados internos, expondo apenas o necessário.
  • OBJETIVO: Proteger dados e garantir integridade.
  • MÉTODO: Atributos private + métodos public (getters/setters).
🎯 ANALOGIA:
  • 🔒 Uma mochila guarda seus pertences. Você só pode acessá-los abrindo o zíper.
  • 🏦 Um caixa eletrônico permite sacar dinheiro, mas você não vê o cofre interno.
  • 📱 Um smartphone tem botões e tela, mas você não vê os circuitos internos.

🔒 Como implementar encapsulamento em Java?

1 Declare os atributos como private
2 Forneça métodos public para acessar (getters) e modificar (setters)

📝 Getters e Setters

public class Pessoa {
    // Atributo privado
    private String nome;

    // Getter - Lê o valor
    public String getNome() {
        return nome;
    }

    // Setter - Define o valor (com validação)
    public void setNome(String nome) {
        if (nome != null && !nome.trim().isEmpty()) {
            this.nome = nome;
        } else {
            System.out.println("Nome inválido!");
        }
    }
}
✅ VANTAGENS DO ENCAPSULAMENTO:
  • 🛡️ Segurança: Dados protegidos de acesso indevido
  • 🔄 Flexibilidade: Mudanças internas não afetam outras classes
  • 📏 Controle: Validações antes de alterar dados
  • 🔧 Manutenibilidade: Código mais fácil de manter

💻 Exemplos Práticos

📌 Exemplo 1: Classe Aluno (sem encapsulamento)

🎯 OBJETIVO: Mostrar o problema de NÃO usar encapsulamento. Atributos públicos permitem valores inválidos. 
package tema09;

public class Exemplo1Aluno {
    // ATRIBUTOS PÚBLICOS (sem encapsulamento)
    public String nome;
    public int idade;
    public double nota;

    public void exibirInfo() {
        System.out.println("Nome: " + nome);
        System.out.println("Idade: " + idade);
        System.out.println("Nota: " + nota);
    }

    public static void main(String[] args) {
        Exemplo1Aluno aluno = new Exemplo1Aluno();

        // ACESSO DIRETO - sem nenhum controle!
        aluno.nome = "João";
        aluno.idade = -5;    // PROBLEMA! Idade negativa!
        aluno.nota = 15.0;   // PROBLEMA! Nota maior que 10!

        System.out.println("--- SEM ENCAPSULAMENTO ---");
        aluno.exibirInfo();

        System.out.println("\n⚠️ PROBLEMAS: idade negativa e nota > 10!");
    }
}

📌 Exemplo 2: Classe Aluno (com encapsulamento)

🎯 OBJETIVO: Mostrar como o encapsulamento com getters/setters protege os dados com validações. 
package tema09;

public class Exemplo2Aluno {
    // ATRIBUTOS PRIVADOS
    private String nome;
    private int idade;
    private double nota;

    // GETTERS
    public String getNome() {
        return nome;
    }

    public int getIdade() {
        return idade;
    }

    public double getNota() {
        return nota;
    }

    // SETTERS (com validação)
    public void setNome(String nome) {
        if (nome != null && !nome.trim().isEmpty()) {
            this.nome = nome;
        } else {
            System.out.println("❌ Nome inválido!");
        }
    }

    public void setIdade(int idade) {
        if (idade >= 0 && idade <= 150) {
            this.idade = idade;
        } else {
            System.out.println("❌ Idade inválida! (0-150)");
        }
    }

    public void setNota(double nota) {
        if (nota >= 0 && nota <= 10) {
            this.nota = nota;
        } else {
            System.out.println("❌ Nota inválida! (0-10)");
        }
    }

    public void exibirInfo() {
        System.out.println("Nome: " + nome);
        System.out.println("Idade: " + idade);
        System.out.println("Nota: " + nota);
    }

    public static void main(String[] args) {
        Exemplo2Aluno aluno = new Exemplo2Aluno();

        System.out.println("--- COM ENCAPSULAMENTO ---");

        // Usando SETTERS (com validação)
        aluno.setNome("Maria");
        aluno.setIdade(22);
        aluno.setNota(9.5);
        aluno.exibirInfo();

        System.out.println("\n--- TESTANDO VALORES INVÁLIDOS ---");
        aluno.setIdade(-5);    // ❌ Bloqueado!
        aluno.setNota(15.0);   // ❌ Bloqueado!
        aluno.setNome("");     // ❌ Bloqueado!

        System.out.println("\n--- DADOS PERMANECEM INTACTOS ---");
        aluno.exibirInfo();
    }
}
📤 Saída:

Nome: Maria
Idade: 22
Nota: 9.5

--- TESTANDO VALORES INVÁLIDOS ---
❌ Idade inválida! (0-150)
❌ Nota inválida! (0-10)
❌ Nome inválido!

--- DADOS PERMANECEM INTACTOS ---

📌 Exemplo 3: Classe Produto (getters/setters com regras de negócio)

🎯 OBJETIVO: Mostrar getters/setters com regras de negócio (validações e cálculos). 
package tema09;

public class Exemplo3Produto {
    private String nome;
    private double preco;
    private int estoque;

    // GETTERS
    public String getNome() { return nome; }
    public double getPreco() { return preco; }
    public int getEstoque() { return estoque; }

    // SETTERS
    public void setNome(String nome) {
        if (nome != null && nome.length() >= 3) {
            this.nome = nome;
        } else {
            System.out.println("❌ Nome deve ter pelo menos 3 caracteres!");
        }
    }

    public void setPreco(double preco) {
        if (preco > 0) {
            this.preco = preco;
        } else {
            System.out.println("❌ Preço deve ser maior que zero!");
        }
    }

    public void setEstoque(int estoque) {
        if (estoque >= 0) {
            this.estoque = estoque;
        } else {
            System.out.println("❌ Estoque não pode ser negativo!");
        }
    }

    // Método com regra de negócio: aplicar desconto
    public void aplicarDesconto(double percentual) {
        if (percentual > 0 && percentual <= 50) {
            double desconto = preco * (percentual / 100);
            preco -= desconto;
            System.out.println("✅ Desconto de " + percentual + "% aplicado!");
        } else {
            System.out.println("❌ Desconto inválido! (1-50%)");
        }
    }

    public void exibirInfo() {
        System.out.println("Produto: " + nome);
        System.out.println("Preço: R$ " + preco);
        System.out.println("Estoque: " + estoque);
    }

    public static void main(String[] args) {
        Exemplo3Produto p = new Exemplo3Produto();

        p.setNome("Notebook");
        p.setPreco(2500.0);
        p.setEstoque(10);

        System.out.println("--- PRODUTO ---");
        p.exibirInfo();

        System.out.println("\n--- APLICANDO DESCONTO ---");
        p.aplicarDesconto(10);
        p.exibirInfo();
    }
}
📤 Saída:
--- PRODUTO ---
Produto: Notebook
Preço: R$ 2500.0
Estoque: 10

--- APLICANDO DESCONTO ---
✅ Desconto de 10% aplicado!
Produto: Notebook
Preço: R$ 2250.0
Estoque: 10
